## Задача 3. Спецификации линейных моделей

### Постановка

Построить 5 моделей для `medv` и 5 моделей для `log_medv`,
включая модели со взаимодействиями `zn·tax_over_400`
и `indus·tax_over_400`.

### Спецификации

| Модель | Формула |
|---|---|
| `fit_lm_0` | `medv ~ zn + indus + tax_over_400` |
| `fit_lm_1` | `medv ~ tax_over_400 + zn` |
| `fit_lm_2` | `medv ~ tax_over_400 + indus` |
| `fit_lm_3` | `medv ~ tax_over_400 + zn·tax_over_400 + indus` |
| `fit_lm_4` | `medv ~ tax_over_400 + indus·tax_over_400 + zn` |

Аналогично `fit_lm_0_log … fit_lm_4_log` — для `log(medv)`.

## Задача 6. Интерпретация коэффициентов итоговой модели

### Итоговое уравнение
medv = 27.097 + 0.07·zn − 0.423·indus − 1.823·tax_over_400


### Интерпретация

- **Константа (27.097)** — базовый уровень `medv` при нулевых
  значениях всех предикторов.
- **`zn` (+0.07)** — при росте доли жилой застройки на 1 п.п.
  медианная стоимость дома увеличивается на 0.07 тыс. долл.
- **`indus` (−0.423)** — при росте доли промышленных земель
  на 1 п.п. стоимость дома снижается на 0.423 тыс. долл.
- **`tax_over_400` (−1.823)** — в районах с налогом > 400
  стоимость домов в среднем на 1.823 тыс. долл. ниже
  при прочих равных.

### Вывод

Модель подтверждает интуитивные ожидания:
жилая застройка повышает цену, промышленность — снижает,
высокий налог связан с более низкой стоимостью жилья.

## Итоговые выводы по работе

1. **Распределение `medv` не является нормальным** — логарифмирование
   улучшает ситуацию, но не делает распределение идеально нормальным.
2. **Сила связей зависит от класса `tax_over_400`**: в районах
   с высоким налогом связи `zn` и `indus` с `medv` ослабевают в 2–3 раза.
3. **LOOCV позволяет ранжировать модели** без отложенной выборки,
   но требует значительных вычислительных ресурсов.
4. **Простая линейная модель `fit_lm_0`** без взаимодействий оказалась
   точнее более сложных спецификаций — как по LOOCV (59.99 vs 61.54–62.40),
   так и на отложенной выборке (79.81 vs 81.59 для лог-модели).
5. **Логарифмирование зависимой переменной** не улучшило прогнозную
   точность на тесте, хотя формально снизило асимметрию распределения.
6. **Интерпретация коэффициентов** итоговой модели соответствует
   экономическому смыслу признаков.
